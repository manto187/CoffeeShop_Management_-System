# ☕ Hali's Odyssey - Coffee Shop Management System
A comprehensive, console-based Management System for coffee shops, designed to streamline operations for both administrators and customers. This program offers a robust set of features ranging from inventory tracking to customer loyalty programs.


## 🚀 Features

### 👤 Customer Features
- **Order Coffee**: Direct interface for browsing menu items and placing orders.
- **View Menu**: Real-time display of available items, prices, and stock levels.
- **Order History**: Personalized tracking of previous purchases.
- **Loyalty Program**: Automatic reward tracking (earn free coffee after 5 orders!).
- **Feedback System**: Provide ratings and comments on service.

### 🔐 Admin Features
- **Inventory Management**: Update stock levels and track availability.
- **Menu Customization**: Add new items, remove old ones, and update pricing.
- **Sales Monitoring**: View all transaction history and total revenue reports.
- **Employee Management**: Track staff IDs, positions, and salaries.
- **Performance Analysis**: View most popular items and latest customer feedback.


## 🛠️ Technical Stack
- **Language**: C++
- **Storage**: Persistent File-based system (`.txt` database files)
- **Architecture**: Procedural with specialized modules for file handling and UI management.

---

## 📥 Getting Started

### Prerequisites
- A C++ compiler (GCC, MinGW, Clang, or MSVC).
- Windows OS (utilizes `conio.h` for input handling).

### Compilation
Open your terminal and run:
```bash
g++ coffeeMain.cpp -o CoffeeShop.exe
```

### Execution
Run the compiled executable:
```bash
./CoffeeShop.exe
```
